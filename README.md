# Панель здоровья — демонстрационная версия

Рабочий прототип интерактивной панели здоровья: один HTML-файл, который
открывается по ссылке и работает целиком в браузере.

**Открыть:** https://emanita-lang.github.io/family-office-panel/

## Что умеет

- **Анализы** — показатели с коридором нормы, история замеров, график динамики
- **Врачи** — визиты, заключения, назначения
- **Витамины** — приём, остаток, дата следующего заказа
- **Чтение PDF** — документ загружается прямо в панель, текст извлекается
  в браузере, данные раскладываются по разделам (анализы / врачи / витамины)
- **Питание** — дневник КБЖУ, суточный итог, столбики по дням с линией цели
- **Форма** — тренировки, цели на неделю и месяц
- **Научная лента** — свежие публикации по теме долголетия из открытых баз
  Europe PMC и PubMed, обновление в окнах 09:00 / 13:00 / 17:00 / 21:00

## Как устроено

Один самодостаточный файл. Никаких внешних библиотек по сети, никаких
серверов и ключей доступа. Графики рисуются на SVG вручную, чтение PDF —
встроенной библиотекой, вшитой в тот же файл.

**Данные никуда не отправляются.** Всё, что вы введёте, остаётся в памяти
вашего браузера (localStorage) на вашем устройстве. Ни на этот сайт, ни
куда-либо ещё они не уходят. Кнопки «Скачать данные» и «Загрузить данные»
позволяют перенести их между устройствами файлом.

Единственные обращения в интернет — к открытым научным базам Europe PMC
и PubMed за списком публикаций. В запросе передаётся только тема поиска.

## Данные в демонстрации вымышленные

Показатели, назначения и записи на этой странице — придуманный пример
для демонстрации интерфейса. Это не чьи-то настоящие медицинские данные.

## Не медицинский сервис

Панель ничего не диагностирует и не назначает. Цели и нормы задаёт
пользователь или его специалист — панель только показывает и считает.
Научная лента приводится информационно и не является рекомендацией.
